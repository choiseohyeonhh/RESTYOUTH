## 1. 한 줄 소개

하루 24시간 중 **기본값은 '쉼'**. 일한 시간과 잔 시간만 버튼으로 기록하는 자학 개그형 타임트래커입니다.
"쉬었음 청년" 밈을 비틀어 내가 얼마나 쉬었는지 위젯과 결산으로 보여 줍니다.

- **톤**: 남을 비웃지 않고, 나를 놀리면서 위로하는 앱
- **주 사용자**: 실제로 쉬고 있는 청년이 셀프 위로용으로 쓰는 것을 기준으로 문구를 쓰고, 직장인·학생도 밈으로 웃을 수 있게 만든다
- **언어**: 한국어 전용
- **플랫폼**: iPhone, **iOS 18 이상**

## 3. 핵심 개념: 하루는 세 가지 상태

| 상태 | 기록 방법 | 색 (가안) |
|---|---|---|
| **쉼** | 기본값. 아무것도 안 누르면 쉼 | 연두 |
| **일함** | '일했음' 버튼으로 시작과 종료 | 회색 |
| **잠** | '잠잤음' 버튼으로 시작과 종료, 또는 사후에 시간 입력 | 남색 |

- 한 번에 한 상태만 진행할 수 있다. 일하는 중에 '잠잤음'을 누르면 일을 끝내고 잠을 시작한다(반대도 같다).
- 잠을 기록하지 않으면 그 시간은 쉼으로 쌓인다. 기록하지 않은 시간은 전부 쉼이라는 철학을 지킨다.
- 잠은 아침에 몰아서 넣는 경우가 많을 것으로 보고, **"어젯밤 잠 추가"** 바로가기를 둔다. 기본값은 23:00–07:00이고, 마지막으로 입력한 값을 기억한다.

## 4. 계산 규칙

모든 수치는 `Session` 기록에서 그때그때 계산한다. 결과를 따로 저장하지 않는다.

### 4.1 기본 공식

어떤 구간 `[a, b)`에서 (`b`가 미래면 지금까지만 계산):

```
경과 = min(b, now) − max(a, 설치시각)
일함 = Σ (일함 세션과 구간이 겹치는 길이)
잠   = Σ (잠 세션과 구간이 겹치는 길이)
쉼   = 경과 − 일함 − 잠
```

- 진행 중인 세션(`endAt == nil`)은 지금 시각까지 계산한다.
- 세션은 종류에 상관없이 서로 겹칠 수 없다.
- 시간대는 계산하는 순간의 기기 시간대를 쓴다.

### 4.2 날린 일당

```
근무창     = 공휴일이 아닌 평일 09:00–12:00, 13:00–18:00 (하루 8시간)
날린 시간  = 근무창 중 '일함'이 아닌 시간 (잠도 포함 — "낮잠도 엄연히 날린 일당")
날린 일당  = floor(날린 초 × 그해 최저시급 ÷ 3600) 원
```

- 예: 평일 5일을 전부 쉼 → 40시간 × 10,320원 = **412,800원**
- 최저시급은 **날짜가 속한 연도의 값**을 쓴다. 연도를 넘는 결산도 정확하게 나온다.
- 공휴일에는 대체공휴일과 임시공휴일을 포함한다. 연도별 목록을 상수로 관리한다.

### 4.3 최장 연속 쉼 ("무사고 쉼")

- **일함 세션이 없는 연속 구간**을 말한다. 잠은 연속 기록을 끊지 않는다.
- **현재 기록**: 마지막 일함이 끝난 때(없으면 설치 시각)부터 지금까지. 예: "현재 31시간째 무사고 쉼"
- **역대 최고**: 설치 이후 가장 긴 구간
- **결산 기간 최고**: 주간·월간 결산 범위 안에서 가장 긴 구간

### 4.4 쉬었음 등급

**기준값**: 직전 주 월–금 중 공휴일을 뺀 날들의 하루 평균 쉰 시간(잠 제외). 설치 당일처럼 일부만 기록된 날과 아직 끝나지 않은 날은 빼고, **온전히 기록된 날**만 센다.

| 레벨 | 등급 | 평일 하루 평균 쉼 |
|---|---|---|
| 1 | 견습 쉬었음러 | 6시간 미만 |
| 2 | 숙련 쉬었음러 | 6–9시간 |
| 3 | 프로 쉬었음러 | 9–12시간 |
| 4 | 쉬었음 장인 | 12–14시간 |
| 5 | 쉬었음 국가대표 🏅 | 14시간 이상 |

- 경계값은 상수로 두고, 베타 테스트 후 조정한다.
- **확정 시점**: 매주 월요일 00:00에 지난주 등급을 확정한다.
- **심사 보류**: 설치 후 기록이 있는 평일이 3일 미만이면 "등급 심사 중"으로 표시한다.
- **이번 주 예상 등급**: 이번 주에 끝난 평일이 하루라도 있으면 그 평균으로 표시한다. 없으면 지난주 확정 등급을 보여 준다.
- **등급이 바뀌었을 때 메시지** (오르든 내리든 둘 다 축하한다)

| 변화 | 메시지 예시 |
|---|---|
| 강등 | 🎉 **강등을 축하합니다!** 프로 → 숙련 쉬었음러. 이번 주 정말 많이 움직이셨네요. 수고했어요. |
| 승급 | 🏅 **승급!** 숙련 → 프로 쉬었음러. 잘 쉬는 것도 실력입니다. |
| 유지 | 등급 유지. 꾸준함은 재능이에요. |

  - 시작이 종료보다 앞이어야 한다.
  - 미래 시각은 넣을 수 없다.
  - 설치 이전 시각도 허용한다(이전 기록을 넣고 싶을 수 있음). 설치 시각은 그만큼 앞으로 당겨진다.

## 6. 위젯 · 제어 센터 · 액션 버튼 · Live Activity

| 위치 | 종류 | 내용 | 인터랙션 |
|---|---|---|---|
| 홈 화면 | **large** | 24시간 바, 오늘 쉼·일함·잠 수치, 현재 상태와 경과 시간, 등급, 무사고 쉼 | [일했음] [잠잤음] 버튼 (App Intent) |
| 잠금화면 | **rectangular** | 현재 상태 + 경과 시간 + 오늘 쉼 비율 바 | 탭하면 앱 열림 |
| 잠금화면 | **circular** | 오늘 쉼 비율 게이지 + 상태 아이콘 | 탭하면 '일했음' 토글 |
| 제어 센터 | Control 2개 | '일했음' 토글, '잠잤음' 토글 | 바로 토글 |
| **액션 버튼** | 위 Control 중 하나 지정 | 사용자가 설정 앱에서 지정 | 꾹 누르면 토글 |
| 다이나믹 아일랜드 / 잠금화면 | Live Activity (일함만) | "근무 중 00:42" | [일 끝] 버튼 |

**참고**
- 액션 버튼은 iPhone 15 Pro 이후 모델에만 있다. 다른 기기에서는 제어 센터로 쓰면 된다.
- 앱 안에 "액션 버튼에 '일했음' 넣는 법" 안내 화면을 하나 둔다.

**기술 메모**
- 위젯은 자주 새로고칠 수 없다.
  - 경과 시간 숫자: `Text(date, style: .timer)`로 시스템이 알아서 갱신한다.
  - 24시간 바: 15분 간격 타임라인으로 그린다.
  - 버튼을 누르면 `WidgetCenter.reloadAllTimelines()`를 호출한다.
- Live Activity는 최대 8시간까지 유지된다. 8시간이 지나면 Live Activity만 끝나고 근무 기록은 계속된다.

## 8. 문구 가이드

**원칙**
1. 놀리는 대상은 **밈과 상황**이지 사람이 아니다.
2. 사람의 가치를 생산성으로 판단하는 표현을 쓰지 않는다.
3. 금지어: 백수, 한심, 루저, 잉여, 낙오, 정신 차려 같은 비하·훈계 표현
4. 결산과 등급 메시지는 항상 위로 한 줄로 끝낸다.
5. 숫자로 놀리고 말로 감싼다. 예: "날린 일당 412,800원. 근데 그 시간에 당신이 버틴 것도 일이에요."

**샘플 문구**
- 첫 실행: "환영합니다. 지금부터 당신의 모든 시간은 '쉼'으로 기록됩니다. 일했을 때만 알려 주세요."
- 첫 '일했음': "기록 개시. 쉬었음 관리공단이 놀라고 있습니다."
- 하루 종일 쉰 날: "오늘 무사고 24시간. 몸이 쉬라고 했나 봐요."
- 무사고 기록 경신: "신기록! 47시간 무사고 쉼. 기록은 깨라고 있는 거죠. (그래도 천천히)"

```swift

@Model

    var id: UUID = UUID()
    var kindRaw: String = SessionKind.work.rawValue
    var startAt: Date = Date.now
    var endAt: Date? = nil          // nil = 진행 중
    var createdAt: Date = Date.now
    var updatedAt: Date = Date.now
}
```

- **CloudKit 호환 규칙**: 모든 속성에 기본값을 두고, `@Attribute(.unique)`는 쓰지 않는다. 나중에 iCloud 동기화를 켜기 쉽게 하기 위해서다.
- **App Group에 저장 (UserDefaults)**: `installedAt`, `lastConfirmedGrade`, `lastSleepPreset`, `userDisplayName`
- **App Group 컨테이너에 저장 (SwiftData)**: 앱과 위젯이 같은 저장소를 쓴다.

## 11. 출시 단계 (개발 경력 0을 고려한 계획)

|---|---|---|
| **0. 준비** | 개발 환경 갖추기 | Mac + Xcode 설치, Apple Developer Program 가입 (연 $99, TestFlight와 출시에 필요) |
| **1. 뼈대** | 시뮬레이터에서 버튼이 눌린다 | 프로젝트 생성, `Session` 모델, 계산 로직과 단위 테스트, 메인 화면 |

| **4. 결산** | 웃을 거리가 생긴다 | 주간·월간 결산, 날린 일당, 무사고 쉼, 등급과 축하 메시지, 주간 알림 |
